# 🌿 Vive Sano — Proyecto HTML para Systeme.io

Proyecto completo en **HTML5, CSS3 vanilla y JavaScript ES6** diseñado para ser alojado o migrado directamente a la plataforma **Systeme.io**.

## 📌 Páginas Incluidas

1. **`index.html`** — Landing page principal de captación de leads y campaña directa de la Guía Gratuita de Vive Sano por Gloria Molina.
2. **`gracias.html`** — Página de agradecimiento y confirmación de descarga del archivo PDF.
3. **`guia-digestiva.html`** — Squeeze page de 2 columnas ultra-enfocada para campañas de Meta Ads / Google Ads.
4. **`programa.html`** — Página de ventas del programa guiado "Construyendo tu Inmunidad".
5. **`pago.html`** — Plantilla de checkout y resumen de pedido seguro.
6. **`gracias-compra.html`** — Página de bienvenida tras adquirir el programa.

## 📁 Archivos de Soporte

- `css/styles.css`: Sistema de diseño responsivo con la paleta de colores oficial de Vive Sano, fuentes de Google Fonts (Playfair Display & Plus Jakarta Sans) y efectos visuales.
- `js/main.js`: Funcionalidad interactiva (Acordeones FAQ, Galería Lightbox, validación de formularios y seguimiento de parámetros UTM).
- `systeme-io-guide.md`: Guía paso a paso sobre cómo vincular los formularios con Systeme.io, etiquetar leads y automatizar correos.
- `assets/images/`: Imágenes de lifestyle, mockups de la guía y fotos de la fundadora Gloria Molina.

## 🚀 Cómo Usarlo

Abre `index.html` directamente en tu navegador para previsualizar las páginas, o revisa `systeme-io-guide.md` para las instrucciones detalladas de integración con Systeme.io.
